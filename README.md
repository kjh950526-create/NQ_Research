# NQ_Research

NQ/MNQ 재량 트레이딩 검증 연구 저장소.

## 폴더 구조
- `docs/` — RESEARCH_LOG.md (마스터 연구 기록, backbone 문서)
- `pd/` — 일별 PD (NinjaTrader 거래 기록, YYMMDD_pd.csv)
- `raw/` — 일별 raw 1초봉 bid/ask 아카이브 (raw_MNQ_..._YYYYMMDD.csv)
- `journal/` — decision_journal_light.xlsx (구글 시트 백업본)
- `daily_merged/` — merged_log.csv (PD+판단 통합 누적, 분석용 마스터 데이터)

## 현재 단계
재량 판단 검증 — "진입 vs 참음" 축. 진입이 baseline보다 나은가 / 참은 자리가 실제 나빴나.
자세한 맥락은 docs/RESEARCH_LOG.md 참조.
